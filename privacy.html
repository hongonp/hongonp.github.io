개인정보처리방침 / Privacy Policy

시행일 / Effective: 2026-10-24

1. 누가 쓰나요 / Who uses this app

video-localizer는 운영자 본인의 Google 계정과 YouTube 채널에서만 쓰는 개인용 도구입니다. video-localizer is a personal tool used only with the operator's own Google accounts and YouTube channels.

2. 요청하는 권한 / Requested Google permissions

  • youtube.upload: 운영자의 채널에 영상을 올립니다. Upload videos to the operator's channel.
  • youtube.force-ssl: 올린 영상의 썸네일·자막 설정, 처리 상태 확인, 댓글 작성. Set thumbnails and captions, check processing status and post comments on uploaded videos.
  • openid, userinfo.email: 어느 Google 계정·채널로 연결했는지 구별합니다. Identify which Google account and channel was connected.

3. 쓰는 방법 / How data is used

위 권한으로 받은 데이터는 운영자가 직접 지시한 업로드·설정·확인에만 씁니다. 광고, 판매, 분석, 인공지능 학습에 쓰지 않습니다. Data obtained with these permissions is used only to perform uploads, settings and checks the operator explicitly requests. It is not used for advertising, sold, used for analytics, or used to train AI models.

video-localizer의 Google 사용자 데이터 사용은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요건을 따릅니다. video-localizer's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 저장 위치 / Storage

  • 로그인 정보(토큰)는 운영자 컴퓨터의 Windows 자격 증명 관리자(보안 저장소)에만 저장합니다. Sign-in tokens are stored only in Windows Credential Manager on the operator's computer.
  • 연결한 채널 이름·ID, 이메일, 업로드 기록(영상 ID 등)은 운영자 컴퓨터의 로컬 파일에만 저장합니다. Connected channel name/ID, email and upload records (such as video IDs) are stored only in local files on the operator's computer.
  • 운영자가 운영하는 서버나 다른 곳으로 보내지 않습니다. Google API 외의 제3자와 공유하지 않습니다. This data is not sent to any server and is not shared with any third party other than Google APIs.

5. 삭제 / Deletion

앱의 「선택 계정 연결 해제」로 로컬 로그인 정보를 지울 수 있고, Google 계정의 타사 액세스 설정에서 권한을 언제든 취소할 수 있습니다. Local sign-in data can be deleted with the app's "disconnect selected account" function, and access can be revoked at any time at Google Account third-party access settings.
